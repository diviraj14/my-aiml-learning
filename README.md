# Machine Learning Algorithms

##  About the Project

This project demonstrates **9 Machine Learning algorithms** using Python and Scikit-learn.

The dataset contains student information such as:

* Hours
* Attendance
* Age
* Marks

The project performs both **Regression** and **Classification** tasks.

##  Algorithms Used

### Classification

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest
5. Support Vector Machine (SVM)
6. Naive Bayes

### Regression

7. Linear Regression
8. Lasso Regression
9. Ridge Regression

##  Technologies Used

* Python
* NumPy
* Pandas
* scikit-learn


##  Evaluation Metrics

The models are evaluated using:

* Accuracy
* R² Score
* Mean Squared Error
* Confusion Matrix
* Classification Report
